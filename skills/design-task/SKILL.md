produce an implementation plan.

- define steps
- identify files
- identify risks
- identify dependencies

```text

└── epics/
    └── EPIC-[EPIC_NUMBER]-[EPIC_NAME]/
       └── tasks/
           ├── [TASK_NUMBER]-[TASK-NAME]/
           │   └── README.md
           ├── [TASK_NUMBER]-[TASK-NAME]/
           │   └── README.md
           └── [TASK_NUMBER]-[TASK-NAME]/
               └── README.md
```
